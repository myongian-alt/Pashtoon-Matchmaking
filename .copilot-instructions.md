# Local Copilot Notes

Canonical instructions live in [../.github/copilot-instructions.md](../.github/copilot-instructions.md).

## Fast Commands

- Install dependencies:
  - `npm install --legacy-peer-deps`
- Start app:
  - `npm run start`
- Type-check before finishing changes:
  - `npx tsc --noEmit`

## Scope Reminder

- Implement product code changes in `src/`.
- Use Supabase logic from `src/lib/auth.ts`, `src/lib/database.ts`, and `src/lib/supabase.ts`.
- For deployment/setup details, use [SUPABASE_SETUP.md](SUPABASE_SETUP.md) and [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md).
